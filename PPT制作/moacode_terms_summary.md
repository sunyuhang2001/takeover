## 第一章 服务定义与性质

### 1.1 平台服务

- 平台定位为面向开发者和技术团队的云资源整合与技术适配平台。
- 平台通过资源管理、技术封装和接口适配，帮助用户更稳定地调用上游技术资源，例如 AI 模型接口。

### 1.2 具体服务模式

- 资源池调用服务：用户通过购买订阅获得共享资源池中的调用额度，平台负责资源池维护和负载均衡。
- 专用资源组服务：平台可将独立上游资源分配给小型用户组协作使用，组内成员共享使用权。

### 1.3 技术中立声明

- 平台仅提供技术管道和资源调度能力。
- 平台声明不会生产、审核或修改用户传输的数据，也不会修改上游返回内容。
- 平台强调自身并非 VPN 或非法国际信道，设计目的仅限于解决开发中的网络连接和接口兼容问题。

## 第二章 用户资格与核心责任

### 2.1 用户资格

- 用户应是具备相应技术能力的开发者、技术专业人士，或代表合法技术团队。
- 使用目的应为合法的软件开发、技术测试或学术研究。
- 个人用户需达到法定成年年龄。
- 代表组织使用时，需有权让组织受本协议约束。

### 2.2 最终责任人原则

- 用户需对自己的项目及账户下发生的 API 调用承担最终责任。
- 平台不对项目合法性、数据处理合规性或生成结果承担责任。

### 2.3 数据保护与合规

#### 2.3.2 跨境数据传输

- 使用服务访问上游资源时，可能发生跨境数据传输。
- 文中提到上游提供商可能会在英国和欧洲经济区以外处理数据，包括美国。
- 用户作为数据控制者，需要自行完成必要的合规动作，例如：
  - 在需要时取得数据主体同意；
  - 在必要时开展 DPIA；
  - 为国际传输配置适当保障措施；
  - 向最终用户清楚说明国际数据传输情况。

#### 2.3.3 数据处理角色

- 用户被界定为数据控制者。
- 平台在处理 API 请求时被界定为数据处理者。
- 上游提供商被界定为次处理者。

### 2.4 禁止用途

#### 2.4.1 未经适当授权不得公开转售

- 不得在未取得必要政府许可或授权的情况下，将平台服务再次封装后向不特定公众提供。
- 页面特别警告，若违反该限制，账户及相关网站资产可能被暂停、取消或永久封禁。

#### 2.4.2 禁止活动

- 网络攻击、恶意消耗资源或抓取数据。
- 处理违法内容。
- 违反上游提供商条款。
- 规避限制或安全措施。
- 非法监视、骚扰或侵犯他人权利。
- 违反《1990 年英国计算机滥用法》或类似法律的活动。

## 第三章 服务费用与订阅规则

### 3.3 退款政策

- 页面说明订阅费用原则上不予退还。
- 同时提到英国消费者仍享有法定消费者权利，例如冷静期与服务不符时的法定救济。
- 页面也列出退款可能受限的情况，例如滥用退款政策或已实际使用部分服务。
- 支付服务商可能会收取一定交易费用。
- 套餐订阅退款会按 Paygo 价格扣除已使用部分。
- 如需主张取消权，页面要求在购买后 14 天内通过工单联系平台。
