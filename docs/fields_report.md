# 路侧数据统计 · 字段映射 · 字段补充方案

- 依据：`bastion/14_roadside_fields.py`（v3 在堡垒机上跑出的结果，v4 在 v3 基础上把已确认的结论写进了规则）和 `bastion/15_audio_probe.py`（音轨检测）。
- 理想字段表：《字段清单 V2.04》，共 110 个字段，其中 P0 65 个。
- 本文只写汇总数字。逐条明细在堡垒机 `D:\takeover_audit\14_fields\`：`字段映射表.xlsx`、`events_roadside.csv`、`gantry_cases.csv` 等。

## 0. 结论

1. **路侧数据分两段**：
   - 2024 年主要是龙门架视频，2024-04 至 2025-03，17 个路口，105 个案例。
   - 2025 年主要是路侧 participant（周边交通参与者）数据，2025-03 至 05，52.5 小时，137 GB。
   - 结构化的路侧 JSON（participant、信号、交通流、事件）在 2024 年只有 2024-01-02 和 02-19 两天。
   - 能对上事件的路侧数据共 59 个事件：有路口视频拍到这辆车的 41 个（按经纬度补查后，原 24 个 + 新增 17 个），有路侧周边车辆数据的 18 个（2025 年 16 个，2024 年 2 个）。
2. **现有表格普遍有的列**：VIN、时间、drive_mode、经纬度、速度、航向，部分还有纵向/横向加速度。
   - **所有轨迹表都没有**方向盘、制动、油门、档位这几列，只能从视频恢复。
   - 2024 年的 vehicle_track JSON 其实有这几列，但只有两天的数据。
3. **接管请求**：座舱音轨是 PCM 格式，程序可以直接读。检测结果是：只在模式切换那一刻有一声约 2 kHz 的提示音，没有提前、重复的请求提示音；0920 的描述也都是安全员主动接管。所以"是否发出接管请求"判为**否（安全员主动接管）**，请求时间、告警分段等字段判为**不适用**。
4. **按等级看（P0 共 65 个字段）**：
   - **A、B**：现有数据加上视频模型、人工审计，P0 字段基本都能补。
   - **E（2024，36 个）**：轨迹加龙门架视频，驾驶员相关字段补不了。
   - **2025-E**：轨迹加 participant，目标物相关字段全部能从路侧数据提取，驾驶员相关字段补不了。
   - **F**：数量最多（2120 个），只有车辆运动字段。
   - **D、X、H**：基本不可用。

## 3. 规定动作

每个字段按顺序尝试下面这些动作，每个事件用第一个做得到的。

| 代号 | 动作 | 说明 |
|---|---|---|
| D | 直接读取 | 现有表格、JSON、视频里本来就有 |
| C | 计算推导 | 由现有字段计算得到（差分、阈值、匹配路段表、按运营规则判定等） |
| L | 已有人工标注 | 0920 台账里的人工标签和描述 |
| R | 路侧提取 | 从 participant、signal 等 JSON 或运行安全评价结果中取出，或结合自车轨迹计算 |
| M | 模型恢复 | 用模型从视频或音轨恢复，例如视觉里程计恢复轨迹、目标检测测距、DMS、踏板动作识别、提示音检测、路口视频多目标跟踪 |
| V | 视频人工审计 | 人工看视频或路侧回放后逐条标注 |
| X | 外部地图 | OSM / 高德 / 百度路网，有条件时用高精地图：道路等级、限速、车道线、特殊区域、地图匹配 |
| W | 外部气象 | 按日期和位置查历史气象站或再分析数据：天气、温度、湿度、能见度 |
| N | 无法补充 | 这个事件没有能用的数据源，方法再多也补不了 |

## 7. 建议的补充顺序

1. **先做现有数据，不用新工具**：
   - 0920 标签映射：道路类型、天气、光线、交通灯、目标物、描述；
   - drive_mode 和 switch 平台表：控制模式、接管完成状态、ADS 事件；
   - 轨迹差分：速度、加速度、航向、首次转向时间和制动时间的代理值；
   - 按 road_segment_id 匹配 `_local_road_segment`：限速、车道数；
   - 2025 年的 SEC_evaluation / ssm：TTC、最小距离。
2. **再做模型恢复，覆盖面最大**：
   - 座舱 ch2 视频跑 DMS：注意力、视线、手握方向盘，约 330 个事件；
   - 踏板 ch3 视频跑动作识别：首次制动/油门时刻，约 440 个事件；
   - 前视 ch1 视频做目标检测和测距：目标物位置、TTC，313 个事件。
   - C 类（165 个）用视觉里程计恢复自车轨迹，恢复后可以升为 B 类。
3. **人工审计，只针对 A、B、E 共约 170 个事件**：退出原因归类、事故结果、是否真实接管失败、驾驶员接管反应时间。
4. **外部数据，批量查询**：地图匹配（道路等级、车道线），按日期和位置查历史气象（温度、湿度、能见度）。
5. **2024 年的 E 类（22 个）**：对龙门架视频做相机标定和多目标跟踪，得到目标物轨迹，再和 2025 年的 participant 放在同一套字段里。
